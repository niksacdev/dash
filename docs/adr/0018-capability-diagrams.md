# 0018. Illustrate each carousel slide with its own evaluation task

**Status** Accepted

A presenter showing DASH had the same racing illustration for setting an objective, grading cases and explaining a verdict. Nik asked for a diagram specific to each capability and one slide titled **Compare and benchmark multiple models** with the cars. This narrows the race treatment in [0015](0015-industry-carousel.md) and preserves the photography, palette and controls in [0017](0017-overview-controls-and-photography.md).

| Slide | What the presenter can explain |
| --- | --- |
| Business outcome | An EPS extraction objective branches into suggested checks for GAAP basis and fiscal period. |
| Model benchmark | Three illustrative model families share the circuit. Quick compare selects two models per run. |
| Industry scenarios | The approved Financial Services, Manufacturing and planned Automotive photographs and captions stay together. |
| Dataset grading | Follow a case through its answer and rubric to a case score. |
| Run report | Inspect the reason for an example basis mismatch between an expected GAAP figure and an adjusted response. |
| Planned hardware in the loop | Follow a sensor reading through an agent and into a case log, then repeat the observation. |

Reusing the circuit for every slide obscured the difference between scoring a dataset and explaining a result. Four inline vector diagrams load offline and scale with the carousel. Only the current illustration is inserted into the active panel. Circuit imagery and animated car lanes belong to the model benchmark. A short accent travels along a connection while playback is enabled. The diagram labels and relationships remain legible when paused or when the operator requests reduced motion.

Exercise all six slides through automatic and manual navigation in Electron. Check the exact benchmark title, exclusive use of the race artwork, accessible diagram descriptions, stable banner height and phone-width labels.
