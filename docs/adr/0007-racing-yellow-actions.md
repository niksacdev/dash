# 0007. Use racing yellow for DASH actions

**Status** Accepted

## Context and decision

The earlier interface used a red primary action against the red racing banner. Nik asked for Ferrari yellow across buttons. Use racing yellow with charcoal labels for actions in both themes. Give selected controls an inset stroke and disabled controls a muted fill. Keep the banner and racing illustration independent of the action color.

## Alternatives and consequences

Retaining red would have preserved the previous primary button treatment. One shared yellow treatment gives operators the same action cue in Quick compare, dataset runs and the grader library. The design guide owns the exact colors and screenshots. A future change to the interaction convention should identify this decision as its predecessor.
