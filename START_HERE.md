# DASH — start here

DASH (Domain Assessment & Scoring Harness) is Nik’s reusable, local-first model and agent evaluation bench. Scenarios, datasets, graders, models and agent versions are independently configurable. Earnings-release capture is the first workload; its financial schema and business rules belong to a separate use-case pack.

This session contains the seven original artifacts, copied from their exact Library references at the latest available revisions on 2026-11-22 UTC. Start with the platform spec, then the earnings pack and approved design reference.

## Intent to preserve

Target Electron on Nik’s Apple Silicon Mac, using LM Studio/Ollama locally, optional OpenRouter or OpenAI-compatible hosted endpoints, and optional Opik. Preserve fast same-query UI chat checks, job-based dataset runs, persistent run/version comparisons, case drill-down and agent traces. Compare Liquid LFM3, Qwen and Gemma 4 on the same task/data, reporting quality and business outcomes alongside latency, tokens, cost and available device-resource measurements.

Preserve Ferrari red and graphite, the softly varied watery-gray background, straight racetrack lines, and the Open Source / Frontier Labs / FineTuned illustrative cars. Processing uses smoke and shows no winner. The specs distinguish illustration from measured progress and make the actual candidate lanes configurable.
