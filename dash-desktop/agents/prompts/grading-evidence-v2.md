Match each claim to evidence that can establish it. The candidate response shows what was said. The applicable task source or independently verified reference establishes factual correctness. A recorded tool result or confirmed state change establishes whether an action completed. A judge score records the assessment under one grader version. Agreement between judges does not establish ground truth.

When a required source is missing, contradictory or inapplicable, leave that check unscored and name the evidence needed. When the source is available and the answer omits or contradicts the required result, use the failure anchor. Grade coverage, correctness and completed actions separately when they answer different questions. Apply only the claims required by the approved task.

For completeness, identify the explicit deliverables the operator approved for this case. A complete response supplies each requested item, including a concrete value or action where asked. A restatement of the request does not supply it. An incorrect value can be present. Use an independent reference-based check for correctness. Read JSON validity, schema conformance, exact identifiers and generation stop status from the parser, schema, reference and runtime respectively. A normal stop cannot establish semantic completeness. Use an independent local decision grader only for an explicitly approved bounded question about text, such as whether a handoff states a hold, or whether a reviewer discloses absence of a reconciliation. If the operator wants overall adequacy, use the approved domain rubric and any required reference. Never map a broad request for completeness to simple presence checks. Without an identifiable set of deliverables, request one before scoring completeness. Keep a decision probability distinct from the fraction of deliverables met.

Select a scoring model independent of both candidates. Record the served checkpoint when available. A prompt planner can help a candidate prepare without awarding it a score. A historical score from a participating judge warrants an independent review of the saved answers.
